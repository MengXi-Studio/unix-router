# @meng-xi/unix-router v0.9.0 发布：`defineUniPage` 支持页面级 `style`

> v0.9.0 为 **MINOR** 版本（0.8.3 → 0.9.0），新增「页面级 `style`」能力：在 `defineUniPage` 宏或 `<route-config>` 块中声明 `style`，构建期原样合并进 `pages.json` 对应页面的 `style` 字段，用于按页面开启自定义导航栏（`navigationStyle: 'custom'`）、下拉刷新等。**无破坏性变更**，现有工程升级无需改动代码。

## 一、需求（issue #10）

在 uni-app x 里，`navigationStyle: 'custom'`、`enablePullDownRefresh` 等页面配置只能写在 `pages.json` 的页面 `style` 中。而使用文件路由插件（`routeGen` / `pagesGen`）时，`pages.json` 由页面内的 `defineUniPage` 生成——此前宏只认得 `title` / `name` / `isTab` / `tab` / `meta` / `redirect` / `beforeEnter`，`style` 属未识别字段，被忽略并产生 unknownFields 告警，于是无法按页面开启自定义导航栏：

```ts
// 0.8.x：style 被忽略，pages.json 只有 navigationBarTitleText
defineUniPage({
	name: 'messages',
	title: '消息',
	isTab: true,
	style: { navigationStyle: 'custom' } // ⚠️ 未识别字段（已忽略）
})
```

旧版替代方案只有全局 `globalStyle.navigationStyle`（影响所有页面）或手改生成文件（下次构建被覆盖），均不可接受。

## 二、新能力

`defineUniPage` 增加 `style?: Record<string, any>`，`<route-config>` 块同样支持：

```vue
<script setup>
defineUniPage({
	name: 'messages',
	title: '消息',
	isTab: true,
	// 页面级 style：原样合并进 pages.json
	style: {
		navigationStyle: 'custom',
		enablePullDownRefresh: true,
		// 平台细分字段同样原样透传
		h5: { titleNView: false }
	}
})
</script>
```

生成的 `pages.json`：

```json
{
	"path": "pages/messages/index",
	"style": {
		"navigationBarTitleText": "消息",
		"navigationStyle": "custom",
		"enablePullDownRefresh": true,
		"h5": { "titleNView": false }
	}
}
```

`<route-config lang="jsonc">` 写法同理：

```vue
<route-config>
{ "navigationStyle": "custom" }
</route-config>
```

## 三、合并规则与优先级

- `title` 仍生成 `navigationBarTitleText`，并继续进入路由 `meta.title`；
- `style` 中的键按字面量**原样合并**进 `pages.json` 的页面 `style`，支持嵌套对象（`h5` / `app-plus` / `mp-weixin` 等平台细分）；
- **同名键以 `style` 为准**（`style.navigationBarTitleText` 会覆盖由 `title` 生成的值）；
- 宏与 `<route-config>` 块同时存在时，按既有「宏 > 块」字段级合并：`style` 内同名键取宏、块补充其余键；
- `pages.json` 中手写的非页面字段（`globalStyle`、`uniIdRouter` 等）继续合并保留；
- 函数 / 标识符 / 模板串等无法序列化为 JSON 的表达式会被**告警并忽略该键**（`pages.json` 是纯 JSON，表达不了函数）。

## 四、行为对比

| 场景 | 0.8.3 | 0.9.0 |
| --- | --- | --- |
| `defineUniPage` 声明 `style` | ❌ 忽略 + unknownFields 告警 | ✅ 合并进 `pages.json` |
| `<route-config>` 块声明 `style` | ❌ 忽略 + 告警 | ✅ 合并进 `pages.json` |
| 按页面 `navigationStyle: 'custom'` | ❌ 只能全局或手改 | ✅ 页面级声明 |
| 平台细分（`h5` / `app-plus`） | — | ✅ 原样透传 |
| `title` → `navigationBarTitleText` | ✅ | ✅（不变） |

MINOR 版本（0.8.3 → 0.9.0）：新增页面级 `style` 声明能力，向后兼容，无 API 删改、无破坏性变更。

| 功能 | 0.8.3 | 0.9.0 |

## 七、升级指南

0.8.3 → 0.9.0 **无需改动代码**：

```bash
pnpm add @meng-xi/unix-router@0.9.0
```

使用 uni_modules 形态的工程，请到插件市场更新 `ux-router` 至 0.9.0。升级后即可在页面 `defineUniPage` 中直接声明 `style`（如 `navigationStyle: 'custom'`），无需再改全局 `globalStyle` 或手改 `pages.json`。
